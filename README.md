# NotesWebApp

Веб-приложение для создания, редактирования, просмотра и удаления личных заметок с авторизацией, подтверждением почты и безопасной сменой пароля.

## Основные возможности
- Регистрация нового пользователя с подтверждением email (отправка токена на почту, переход по ссылке для активации аккаунта)
- Востоновление пароля, проверка на ввод старого пароля, проверка ввода числа на почте, хэширование пароля
- Авторизация существующих пользователей
- Смена пароля:
  - Ввод старого пароля
  - Проверка совпадения нового пароля и повторного ввода
  - Если старый пароль введён неверно — вывод ошибки
  - Отправка уведомления на email о смене пароля
- Сброс пароля через почту:
  - Отправка 4-значного кода на email
  - Пользователь вводит код для подтверждения
  - Возможность задать новый пароль после подтверждения
- Создание, редактирование, чтение и удаление **только своих заметок**
- Все заметки конфиденциальны — пользователи не видят заметки других
- Профиль пользователя:
  - Отображение имени и email
  - Кнопка для изменения пароля
- Простой, безопасный и удобный интерфейс для управления личными заметками

## Технологии
- C# (.NET, ASP.NET Core MVC)
- Entity Framework Core (для работы с базой данных)
- SQL Server / SQLite
- HTML, CSS, JavaScript
- Git и GitHub для контроля версий
- MailKit / MimeKit для отправки писем
