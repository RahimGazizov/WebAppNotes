# NotesWebApp
Веб-приложение для создания, редактирования, просмотра и удаления личных заметок с авторизацией и подтверждением почты.

## Основные возможности
- Регистрация нового пользователя с подтверждением email (отправка токена на почту, переход по ссылке для активации аккаунта)
- Востоновление пароля, проверка на ввод старого пароля, проверка ввода числа на почте, хэширование пароля
- Авторизация существующих пользователей
- Создание, редактирование, чтение и удаление **только своих заметок**
- Все заметки конфиденциальны — пользователи не видят заметки других
- Простой и безопасный интерфейс для управления личными заметками

## Технологии
- C# (.NET, ASP.NET Core MVC)
- Entity Framework Core (для работы с базой данных)
- SQL Server
- HTML, CSS, базовый JavaScript
- Git и GitHub для контроля версий

## Установка и запуск
Проект использует следующие библиотеки NuGet:  
- Microsoft.EntityFrameworkCore  
- Microsoft.EntityFrameworkCore.Tools  
- Microsoft.EntityFrameworkCore.Sqlite  
- MimeKit  
- MailKit 
Для запуска проекта:  
1. Склонировать репозиторий:  git clone https://github.com/RahimGazizov/NotesWebApp.git
2. Открыть проект в Visual Studio
3. Установить NuGet-пакеты (Visual Studio предложит автоматически)
4. Применить миграции для создания базы данных: dotnet ef database update
